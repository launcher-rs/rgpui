### 本分支开发中

1. **布局整理**：`rgpui` crate 根目录 ~68 个平铺文件按子系统归档（私模块直搬，
   公模块同名进目录，`chat_ui → chat` 保留弃用别名），`rgpui.rs` 分组注释。
2. **缺口组件**（以 gpui-kit 组件目录为参照找缺口，但不限于它——其他好用的组件
   也可以加；全部直接进 `rgpui` 现有目录，**不建新 crate**）：
   `Sidebar`、`Select`、`Combobox`、`DatePicker`、`ColorPicker`、`Avatar`、
   `Tree`、`Alert`（首批；后续好用的继续加）。
3. **缺口示例**：`dialog` 示例、`sidebar` 演示。
4. **AGENTS.md 精简**（已提交）：475→200 行，修正过期内容。

## 非目标（推迟）

- **Dock 布局**：gpui-kit 级 Dock（标签/分割/持久化）体量大，1.2 只保证现有
  `SplitPane`/`Resizable` 可用，Dock 另行立项。
- **Editor**：需 tree-sitter（C 依赖，WASM 不兼容），`rgpui-editor` 继续预留，
  `input_ui` 现有能力不变。
- **聊天扩展**（Attachment/Bubble/MessageScroller/Marker）：等 `chat_ui` 有真实
  调用方再补，避免无验收标准的堆组件。
