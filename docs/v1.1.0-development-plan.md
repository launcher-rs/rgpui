# rgpui v1.1.0 开发计划

基于 ru_editor 开发体验问题记录和 Velotype 深度分析，提炼 rgpui 核心框架的改进目标。

---

## 一、问题分析总结

### 已有功能（无需修复）

| 功能 | 状态 | 位置 |
|------|------|------|
| 命令面板 | ✅ 已有 | `components/command_palette.rs` |
| 代码缩进指示线 | ✅ 已有 | `input_ui/indent.rs`，`indent_guides: true` |
| 托盘图标 ICO/PNG | ✅ 已支持 | `tray.rs` 的 `create_hicon_from_bytes` |
| 托盘菜单子菜单/Toggle | ✅ 已有 | `tray.rs` 的 `TrayMenuItem` |
| SortableList | ✅ 已有 | `components/sortable_list.rs` |
| 迁移指南 | ✅ 已有 | `docs/migration-guide-from-rgpui-component.md` |

### 不修复的问题

| 问题 | 原因 |
|------|------|
| Entity 与 Global | Rust 设计限制，newtype 模式是标准做法 |
| ru_editor 特定功能 | 属于应用层，不在框架层实现 |

---

## 二、v1.1.0 开发目标

### 高优先级（P0）

#### 1. 搜索/替换组件 (SearchPanel)

**目标**: 提供内置的搜索/替换面板组件。

**功能**:
- 搜索输入框 + 替换输入框
- 匹配计数显示
- 上一个/下一个匹配导航
- 大小写敏感、全词匹配、正则表达式选项
- 全部替换、替换当前匹配

**工作量**: 中（约 1 周）

---

#### 2. 大文件异步加载

**目标**: InputState 支持异步文件加载，避免大文件阻塞 UI。

**功能**:
- `InputState::load_file_async(path)` 异步加载方法
- 加载状态指示（loading spinner）
- 大文件（>10MB）后台读取

**工作量**: 中（约 1 周）

---

#### 3. Tab 虚拟化/懒加载

**目标**: 优化多 Tab 场景的内存占用。

**功能**:
- 不活跃 Tab 的 InputState 可卸载
- Tab 切换时自动保存/恢复状态
- TabManager 组件管理 Tab 生命周期

**工作量**: 大（约 2 周）

---

### 中优先级（P1）

#### 4. 全局通知便捷 API

**目标**: 提供 `cx.push_notification()` 便捷方法。

**功能**:
- 在 AppContext 中添加 push_notification 方法
- 与现有 NotificationCenter 集成

**工作量**: 小（约 1 天）

---

#### 5. 状态栏组件 (StatusBar)

**目标**: 提供内置的状态栏组件。

**功能**:
- StatusBarItem 支持文本、图标、tooltip
- 左对齐/右对齐/居中布局
- 点击事件回调

**工作量**: 中（约 3 天）

---

#### 6. 窗口最小化到托盘 API

**目标**: 提供语义化的 minimize_to_tray() 方法。

**功能**:
- PlatformWindow trait 添加 minimize_to_tray() 方法
- 隐藏窗口 + 触发最小化到托盘事件

**工作量**: 小（约 1 天）

---

#### 7. 统一初始化函数

**目标**: 提供 `rgpui::init_all(cx)` 统一初始化。

**功能**:
- 聚合所有子系统的 init() 调用
- 自动处理初始化顺序依赖

**工作量**: 小（约 1 天）

---

#### 8. 全局窗口管理 API

**目标**: 提供 cx.show_all_windows() 等全局窗口管理方法。

**功能**:
- show_all_windows() 显示所有窗口
- hide_all_windows() 隐藏所有窗口
- minimize_all_windows() 最小化所有窗口

**工作量**: 小（约 1 天）

---

#### 9. Tab 拖拽排序

**目标**: 提供专门的 Tab 拖拽排序组件。

**功能**:
- DraggableTabBar 组件
- Tab 间拖拽重排
- 跨窗口 Tab 拖拽

**工作量**: 中（约 1 周）

---

### 低优先级（P2）

#### 10. 块级渲染组件

**目标**: 支持将文档分割为块进行渲染（为 Markdown 编辑器奠基）。

**功能**:
- BlockRenderer 组件
- BlockKind 枚举（段落、标题、代码块等）
- 块级编辑事件

**工作量**: 大（约 2 周）

---

#### 11. 虚拟滚动增强

**目标**: 优化大文档渲染性能。

**功能**:
- VirtualList 改进，支持动态高度
- 视口可见范围计算
- 只渲染视口附近的元素

**工作量**: 中（约 1 周）

---

#### 12. 源码映射支持

**目标**: 维护内容与源码的双向偏移映射。

**功能**:
- SourceMapping 结构体
- content_to_source() / source_to_content() 方法
- 支持跨块选择

**工作量**: 中（约 1 周）

---

#### 13. 国际化支持

**目标**: 提供简单的国际化支持。

**功能**:
- I18n 模块
- 多语言资源加载
- 翻译宏

**工作量**: 中（约 1 周）

---

#### 14. 主题热重载

**目标**: 主题文件修改后自动生效。

**功能**:
- 内置文件监听
- 主题重新加载
- 窗口样式实时更新

**工作量**: 小（约 3 天）

---

#### 15. 配置持久化 API

**目标**: 提供简单的配置持久化 API。

**功能**:
- ConfigManager 组件
- JSON/TOML 配置读写
- 配置变更通知

**工作量**: 小（约 3 天）

---
