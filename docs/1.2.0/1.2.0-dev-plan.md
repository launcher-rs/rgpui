# 1.2.0 开发文档

> 实现依据本文档；每项完成后勾选。顺序：布局 → 组件 → 示例 → 验证。
> 组件统一约定：中文文档注释、风格走 `Styled`/`Sizable` 等现有 trait、
> 注册进模块 `mod.rs` + `prelude`（如适用）、零 `#[allow(dead_code)]`。
> 组件 API 设计见 `1.2.0-design.md`；本文档由开发计划、搜索实战反馈、发布记录三份文档合并而成。

## B. 缺口组件（全部进现有目录，不建新 crate）

> 以 gpui-kit 为参照找缺口，但它不是上限：其他好用的组件（哪怕 gpui-kit 没有）
> 都可以加。下面的 B1–B8 是首批，后续随时追加。

- [x] B1. **Sidebar**（新文件 `components/sidebar.rs`）：导航侧边栏。
      API Sketch：`Sidebar::new()` + `.item(id, label, icon)` + `.selected(id)` +
      `.on_select(handler)` + `.collapsible(bool)`（折叠仅图标栏）。
      验收：`rgpui_story` 或新示例可点、可折叠；clippy 干净。
- [x] B2. **Select**（结论：`DropdownMenu` 是通用触发器+构造闭包，不适合简单值列表；
      新写 `components/select.rs`：选项 + 选中索引 + 占位符 + `on_change`，实例计数器防 ID 冲突）。
- [x] B3. **Combobox**（可搜索单选/多选下拉）：`Input` + `PopupMenu` 组合，
      落 `input_ui/combobox.rs` 或 `components/combobox.rs`（看依赖方向定）。
- [x] B4. **DatePicker**：日历弹窗 + 日期显示，落 `components/date_picker.rs`。
      最小可用：年月导航 + 日期格 + `on_select(NaiveDate)`（用 `chrono`，已是 workspace 依赖）。
- [x] B5. **ColorPicker**：色相条 + 饱和度面板 + hex 输入，落 `components/color_picker.rs`，
      回调 `on_change(Hsla)`。
- [x] B6. **Avatar**：头像（图片源）+ 字母回退 + 状态圆点，落 `elements/avatar.rs`。
- [x] B7. **Tree**：已存在（`tree.rs`：`TreeItem`/`TreeState`/`Tree` + `init`），无需新写；
      补 `dialog`/`sidebar` 示例时已验证可用。
- [x] B8. **Alert**：多变体提示消息（info/success/warning/danger），落 `elements/alert.rs`
      （与 `dialog/alert_dialog.rs` 区分：Alert 是行内提示条，不是弹窗）。

## 非目标（1.2.0 不做）

- Dock 布局、Editor（tree-sitter）、Sidebar 等组件缺口——另行立项。
- `SearchPanel` 老 RenderOnce 版的重构/删除——保持兼容，只新增实体版（已做：`SearchPanelState`）。
- 防抖的 `cx.debounce` 方法版——先收 `Debouncer` 结构（已做）；方法版等有人用出痛点再说。
- Upload（需原生文件对话框联动，等平台能力）、Mermaid（需渲染器）、Carousel（已放弃结论不变）、
  聊天扩展（Attachment/Bubble/MessageScroller/Marker，等真实调用方再补）。
