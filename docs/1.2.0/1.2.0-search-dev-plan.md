# 1.2.0 搜索实战反馈开发文档

> 来源：ru_editor 搜索边栏实战（`Ctrl+F` 实时搜索 + 匹配高亮 + 右侧边栏），rgpui 1.1.1。
> 状态：研究完成，待开发。本文是 6 项需求的唯一实现依据，开发必须逐项打勾。

## 研究结论总览

| # | 需求 | 研究结论 | 工作量 |
|---|------|----------|--------|
| 1 | 多区间高亮/装饰 API | **已存在**：`TextDecoration` + `TextDecorationCollection` + `InputState::create_decorations_collection`（Monaco 式，编辑跟随，`element.rs:1204` 已渲染）。缺口仅是 `TextDecoration` 被 `pub(crate)` 锁死、`decorations` 模块未导出，外部构造不出来 | 小：公开 + 导出 + 用法文档 |
| 2 | 只读滚动 API | `scroll_to(offset, direction, cx)` 为 `pub(crate)`（`state.rs:1573`），逻辑现成 | 小：加 `reveal_offset` / `reveal_range` 公开包装 |
| 3 | SearchPanel 可嵌入 | `SearchPanel` 是 `RenderOnce` + 构造要 `&mut Context<Self>`（`search_panel.rs:310,480`）。但父组件本就能经 `Context::new`（`context.rs:822`）创建子实体，缺的只是一个 `Render` 实体包装 | 中：新增 `SearchPanelState` 实体（`Render`），老 `SearchPanel` 保持不动 |

| 5 | 防抖原语 | 无。`util/time.rs` 只有时长格式化；定时器用 `cx.background_executor().timer()`（`image_loading` 示例已有用法） | 小：新增 `util::debounce::Debouncer`（generation 计数防竞态） |
| 6 | 自动滚动补文档 | `set_selected_range → move_to → scroll_to`（`movement.rs:42,51`），行为正确但零文档 | 微：补 doc comment |

## 详细设计

### #1 公开装饰 API（P0）

**改动**（`crates/rgpui/src/input_ui/`）：

1. `mod.rs`：`pub(crate) use decorations::TextDecoration;` →
   `pub use decorations::{TextDecoration, TextDecorationCollection};`
   并 `pub mod decorations;`（与 `cursor` 等模块一致）。
2. 不动渲染层（`element.rs:1204` 已按集合顺序合成装饰，低于选区绘制——需核实绘制顺序，
   若选区盖住装饰则调整合成顺序，见验收）。
3. 中文文档：在 `create_decorations_collection` 上追加搜索场景 recipe：

```rust
// 搜索全部匹配标黄：每个匹配一个 TextDecoration，background_color 标黄
let collection = state.create_decorations_collection(
    matches.iter().map(|r| TextDecoration::new(r.clone(), HighlightStyle {
        background_color: Some(Hsla::yellow()),
        ..Default::default()
    })).collect(),
    cx,
);
// 查询变化时：collection.set(new_decorations, cx)
// 当前匹配：仍用 set_selected_range（选区层级高于装饰，天然高亮当前项）
```

**验收**：
- `cargo doc` 无 broken link；`cargo test -p rgpui input_ui` 通过（含既有 2 个装饰单测）。
- 手工：ru_editor 侧用新 API 实现全部匹配标黄 + 当前匹配选区，回测本仓库（口头确认即可）。

### #2 公开只读滚动 API（P0）

**改动**（`state.rs`，紧贴 `scroll_to`）：

```rust
/// 滚动使给定字节偏移可见，不改变光标与选区。
///
/// 首次布局前调用无效果（内部无 layout 时直接返回，与 scroll_to 一致）。
pub fn reveal_offset(&mut self, offset: usize, cx: &mut Context<Self>) {
    self.scroll_to(offset, None, cx);
}

/// 滚动使给定区间可见（以区间起点为准），不改变光标与选区。
pub fn reveal_range(&mut self, range: Range<usize>, cx: &mut Context<Self>) {
    self.reveal_offset(range.start, cx);
}
```

**验收**：单测（headless `TestAppContext` 建 `InputState`？若现有单测无此 harness，
则以 doc example + `cargo test --workspace` 全绿为准）。

### #4 订阅重入：文档 + 报错（P1）

**改动**：

1. `context.rs:134` `subscribe` 与 `:393` `subscribe_in` 的 doc 里各加一句：
   “回调执行时订阅者实体正被可变借用（内部已包 `update`），回调内禁止再对同一实体

2. `entity_map.rs:209` `double_lease_panic` 信息追加：
   `"…（常见原因：在 subscribe/subscribe_in 回调内又 update 了同一实体，请直接使用回调参数）"`。

**验收**：`cargo test --workspace` 全绿；手工触发一次重入，确认新报错含订阅提示。

### #5 防抖原语（P1）

**改动**：新增 `crates/rgpui/src/util/debounce.rs`（`util/mod.rs` 注册并 `pub use`）：

```rust
/// 防抖器：连续触发时只执行最后一次（generation 计数防旧任务覆盖新结果）。
pub struct Debouncer {
    generation: Arc<AtomicU64>,
}

impl Debouncer {
    pub fn new() -> Self;
    /// 请求执行：取消之前未执行的回调，`duration` 后若无更新的请求则运行 `callback`。
    /// `callback` 在后台任务中运行。调用方传 `&cx.background_executor()` 即可：
    /// `debouncer.debounce(&cx.background_executor(), duration, callback)`。
    pub fn debounce(
        &self,
        executor: &BackgroundExecutor,
        duration: Duration,
        callback: impl FnOnce() + Send + 'static,
    );
}
```

实现要点：`generation += 1` 后 `executor.spawn` + `executor.timer(duration)`，
await 后比较 generation，未变才执行 `callback`。`Send` 约束：回调不得捕获非 Send 的
`&mut Context`，文档里写明（ru_editor 场景：回调里发 channel / 设 Atomic，由 UI 线程消费，
或回调仅做纯计算后经 `update_entity` 写回）。有意吃 `&BackgroundExecutor` 而非
`&mut App`：单测可用 `TestDispatcher` 虚拟时钟确定性验证（见 `debounce.rs` 底部单测）。

**验收**：单测（虚拟时间？若无 mock 时钟，用小 duration 真睡 10ms/50ms 断言只执行最后一次；
挂 `util` 单测）。

### #6 自动滚动补文档（P1）

**改动**：`set_selected_range`（`state.rs:1781`）doc 追加：

## 开发顺序与分支

分支：`feat/1.2.0-search`（从 main 切）。顺序：#1 → #2 → #6（input_ui 一锅出，一次验证）
→ #4（两处小改）→ #5（util 新文件）→ #3（独立文件，单独验证）。
每步 `cargo check -p rgpui`；收尾 `cargo check --workspace + fmt + clippy + test`，
单 PR（`feat: 1.2.0 搜索实战反馈 6 项`）。

## 非目标（1.2.0 不做）

- Dock 布局、Editor（tree-sitter）、Sidebar 等组件缺口——另行立项。
- `SearchPanel` 老 RenderOnce 版的重构/删除——保持兼容，只新增实体版。
- 防抖的 `cx.debounce` 方法版——先收 `Debouncer` 结构；方法版等有人用出痛点再说。
