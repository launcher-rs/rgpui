# 1.2.0 组件设计文档

> 灵感来源：gpui-kit（37 组件目录）为参照，shadcn、Ant Design（含 AntDX AI 组件）
> 找好用的。gpui-kit 没有但好用的也加。全部直接进 `rgpui` 现有目录，不建新 crate。
> 约定：中文文档注释；builder 风格；`Styled`/`Sizable` 等现有 trait；中文注释覆盖所有公开项。

## B1. Sidebar（`components/sidebar.rs`，新建）

导航侧边栏（对标 shadcn Sidebar / AntDX Conversations 承载体）。

```rust
pub struct Sidebar { items: Vec<SidebarItem>, selected: Option<SharedString>, collapsible: bool, collapsed: bool, on_select: Option<Rc<...>> }
pub struct SidebarItem { id: SharedString, label: SharedString, icon: Option<IconName> }

impl Sidebar {
    pub fn new() -> Self;
    pub fn item(mut self, id: impl Into<SharedString>, label: impl Into<SharedString>, icon: Option<IconName>) -> Self;
    pub fn selected(mut self, id: impl Into<SharedString>) -> Self;
    pub fn collapsible(mut self, collapsible: bool) -> Self;
    pub fn on_select(mut self, handler: impl Fn(&SharedString, &mut Window, &mut App) + 'static) -> Self;
}
// RenderOnce 即可（状态由父持有），selected 变化父 cx.notify()
```

```rust
pub struct Combobox { input: Entity<InputState>, items: Vec<SharedString>, filtered: Vec<usize>, multiple: bool, selected: Vec<usize>, on_change: ... }
// 需要 Entity（过滤状态 + 订阅输入变更）→ 实现 Render，父 cx.new 持有。参考 SearchPanelState 模式。
```

## B4. DatePicker（`components/date_picker.rs`，新建）

日历弹窗 + 日期显示。最小可用：年月导航 + 日期格 + `on_select(NaiveDate)`。
`chrono` 已是 workspace 依赖。月份网格纯 div 渲染，弹窗复用 `Popover`。

## B5. ColorPicker（`components/color_picker.rs`，新建）

色相条 + 饱和度明度面板（canvas 或 div 渐变近似）+ hex 输入框，回 `on_change(Hsla)`。
精度要求不高（UI 取色），canvas 自绘可接受。

## B6. Avatar（`elements/avatar.rs`，新建）

头像：图片源（`img` 复用）+ 无图时首字母回退 + 右下状态圆点（online/offline/busy）。
纯 RenderOnce div 组合，无状态。

## B7. Tree（`list/tree.rs`，新建，与 `list/` 同目录）

树形组件：缩进线、展开/折叠三角、选中高亮。
`TreeNode { id, label, children, expanded }` + `TreeState`（展开集合 + 选中）。
虚拟化先不做（节点数 < 1k 直接渲染；大数据走 VirtualList 自行组装，文档注明）。

## B8. Alert（`elements/alert.rs`，新建）

行内提示条（对标 AntD Alert）：info/success/warning/danger 四变体 + 图标 + 可关闭。
与 `dialog/alert_dialog.rs` 区分（那是模态弹窗）。

## B9. 小件九连（shadcn/AntD 共有，rgpui 缺的）

全是纯 RenderOnce div 组合，无状态，单个文件 50–150 行：
`Breadcrumb`（路径导航，`elements/breadcrumb.rs`）、`Pagination`（页码导航，
`components/pagination.rs`，`on_change(usize)`）、`Steps`（步骤条，
`components/steps.rs`）、`Timeline`（时间线，`components/timeline.rs`）、
`Rate`（星级评分，`components/rate.rs`，`on_change(u8)`）、`Popconfirm`
（气泡确认，`menu/popconfirm.rs`，复用 `Popover` + 双按钮）、`Toggle`/`ToggleGroup`
（切换按钮，`elements/toggle.rs`）、`Card`（卡片容器 header/content/footer，
`elements/card.rs`）、`Typography`（`Title`/`Text`/`Link` 排印辅助，`elements/typography.rs`）。

## B10. AI-chat 件（对标 AntDX，落 `chat/` 目录——A3 搬迁后）

`chat_ui.rs` 已有 Message/MessageGroup；补：
`Prompts`（提示词芯片组，`on_pick`）、`Suggestion`（追问建议行）、
`ThoughtChain`（思维链步骤折叠列表）、`Attachments` + `FileCard`（附件列表）、
`Sources`（引用来源 chips）、`Actions`（消息操作行：复制/赞/踩）、`Sender`

`Conversations` 不做新组件（= Sidebar 用法，文档注明）。
