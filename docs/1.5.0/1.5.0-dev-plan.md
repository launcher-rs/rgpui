## 二、借鉴候选

### 2.1 Zed `crates/gpui`——rgpui 基本是上游超集

逐项核对后，`inspector`/`bounds_tree`/`taffy`/`svg_renderer`/`tab_stop`/`arena`/
`queue`/`subscription`/`style`/`gestures`/`platform_scheduler`/`shared_uri` 等
**rgpui 全都已有**（多数更全，如 `inspector` rgpui 570+1265 行 vs 上游 271 行）；
`elements/`、`window/`、`app/`、`keymap/`、`platform/`、`text_system/` 目录为超集或逐名一致。

| 候选 | 价值 | 成本 | 说明 |
|------|------|------|------|
| `debug_overlay.rs` | 中 | 低 | 直接写 `Scene` 的帧耗时浮层（CUR/1%/10%/MAX），**零失效、不触发新帧**；rgpui 现有 `fps_hud` 是走布局的 view 版，替代不了 |
| `randomized_element_tree.rs` | 中高 | 高 | 随机元素树压力/属性测试（~1.7k LOC），属测试基建，收益靠长期跑 CI |
| profiler `journal.rs` + `hang.rs` | 中高 | 高 | profiler 从「线程计时」重构成「事件流 journal + 事后卡顿检测」，横切 scheduler/绘帧，等于重做数据模型 |

> 备注：Zed `randomized_element_tree` 提示「深树每元素递归一次，无 `stacker` 会在几百元素时爆 2MB 线程栈」——rgpui 已用 **`stacksafe`**（底层即 `stacker`）覆盖
> `elements/div.rs` 与 `taffy.rs` 的递归点，**不构成缺口**。

## 三、次级待办（细审发现、本轮未修，记录备查）

- **Code Action 位置编码**：落笔偏移把 LSP 位置直接当**字节列**（`lsp/types.rs`），
  真 LSP 默认 `positionEncoding` 是 UTF-16；含非 ASCII 行时偏移可能落在字符中间，
  后续 `Rope::replace` 对非字符边界会 panic。需要统一的 UTF-16↔byte 换算（或
  `is_char_boundary` 校正）。**优先级高，但涉及 LSP 层设计，单独评估。**
- **Code Action 同起点编辑顺序**：`sorted_by_key(Reverse(start))` 对相同 `start`
  保持原序，未按 LSP 约定（同起点先 insert、后 remove/replace）排序。
- **禁用态 a11y**：`Checkbox`/`Radio`/`Slider` 禁用时只是「不挂动作」，框架
  `write_a11y_info` 没有 `disabled` 输出；建议补 `aria_disabled` 并在三处使用。
- **`Radio` 的 `aria_selected`**：ARIA 里 `radio` 用 `aria-checked`，`aria-selected`
  非其支持属性（照抄 gpui-kit 的做法，严格说非法）；待确认是否去除。
- **`Both` 轴 + `overscroll` 不生效**：经 `Scrollable::overscroll` 的 `Both` 轴滚动区，
  纵向增量不会冒泡出去，`pull` 从不触发（布局测试无法构造）。本次「按轴独立判定」的
  修复主要保护公开的 `Overscroll::new(..., Both)` 直用路径；`Both` 经 Scrollable 的
  行为需单独排查。
- 越界回弹到边后**首个滚轮事件被吞**（`last_offset` 只在滚轮路径更新）。
- **`theme_watcher` 假实现未删**：`crates/rgpui/src/theme_watcher/` 是与真主题系统
  并行、硬编码十六进制色的一套 `ThemeWatcher`/`ThemeManager`（自带 3 值 `ThemeMode`，
  含 `System`），且经 `prelude` 导出同名 `ThemeMode`，与 `theme::ThemeMode`（仅
  Light/Dark）并存易误用。**未在本轮删除**：它是 1.1.0 起已发布的公开 API，删除属
  破坏性变更，须走 2.0 大版本；本轮已把真正的主题目录热重载做进 `ThemeRegistry`
  （见 §二 表），`theme_watcher` 的移除单独排期。

## 四、发版动作（1.5.0 收尾）

1. `[Unreleased]` 定版为 `## [1.5.0] - <日期>`。
2. bump 根 `Cargo.toml` `version` 与 `[workspace.dependencies]` 里 13 个自家 crate 的 `version`。
3. **`crates/rgpui-linux/Cargo.toml` 改回 `version.workspace = true`**。
4. `cargo publish -p rgpui --dry-run --registry crates-io` 校验。
5. 开 PR 合入 main（Squash + Conventional Commits；`main` 未开分支保护，靠自觉等 CI 全绿再合）。
