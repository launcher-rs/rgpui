# rgpui

rgpui is a cross-platform GPU-accelerated UI framework ported from [zed-industries/gpui](https://github.com/zed-industries/zed) and [longbridge/gpui-component](https://github.com/longbridge/gpui-component).

## Features

- GPU-accelerated rendering
- Cross-platform support (Windows, macOS, Linux, Web/WASM)
- Rich component library
- Markdown rendering
- System tray integration
