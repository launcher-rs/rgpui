# 国际化（i18n）

**目录：** [概述](#概述) · [快速入门](#快速入门) · [I18nManager](#i18nmanager) · [全局管理器](#全局管理器) · [I18nText 组件](#i18ntext-组件) · [复数规则](#复数规则) · [语言目录加载](#语言目录加载) · [最佳实践](#最佳实践)

## 概述

`rgpui::i18n` 提供多语言文本管理：把 key 映射到当前语言的文本，支持
`{name}` 占位符插值、回退语言、复数形式与语言快照。

**模块路径：** `rgpui::i18n::{I18nManager, I18nText, PluralRule, I18nSnapshot, Locale, Translation}`
（`crates/rgpui/src/rgpui.rs:284`，**不**在 crate 根重导出，也不在 prelude）。

**核心类型：**

| 类型 | 作用 | 位置 |
|------|------|------|
| `I18nManager` | 翻译数据 + 当前语言，实现 `Global` | `i18n/mod.rs:33` |
| `I18nText` | 渲染期取翻译的文本组件 | `i18n/mod.rs:183` |
| `PluralRule` | 单/复数 key 选择 | `i18n/mod.rs:227` |
| `I18nSnapshot` | 当前语言 + 回退语言快照 | `i18n/mod.rs:46` |
| `Locale` | 语言代码（`= String`） | `i18n/mod.rs:18` |

**查找顺序：** 当前语言 → 回退语言 → key 本身（查不到时返回 key，渲染不断线）。

## 快速入门

```rust
use std::collections::HashMap;
use rgpui::i18n::I18nManager;

let mut i18n = I18nManager::new("zh-CN");
i18n.load_translations_map("zh-CN", HashMap::from([
    ("greeting".to_string(), "你好，{name}！".to_string()),
]));
i18n.load_translations_map("en", HashMap::from([
    ("greeting".to_string(), "Hello, {name}!".to_string()),
]));

// t(key, args) 支持 {name} 插值
assert_eq!(i18n.t("greeting", &[("name", "rgpui")]), "你好，rgpui！");
i18n.set_locale("en");
assert_eq!(i18n.t("greeting", &[("name", "rgpui")]), "Hello, rgpui!");
```

从 JSON 字符串加载（`serde_json`，扁平 `{ "key": "文本" }` 结构）：

```rust
i18n.load_translations("en", include_str!("en.json"))?;  // anyhow::Result<()>
```

完整可运行示例见 `examples/showcase/src/bin/i18n.rs`：
`cargo run -p showcase --bin i18n`。

## I18nManager

`crates/rgpui/src/i18n/mod.rs:33`。实现 `Global`（`:42`），因此可放进 `cx.set_global`。

| 方法 | 签名 | 说明 |
|------|------|------|
| `new` | `(current_locale: &str) -> Self` | 创建管理器（`:55`） |
| `with_fallback` | `(self, fallback: &str) -> Self` | 设置回退语言（`:64`） |
| `load_translations` | `(&mut self, locale, json: &str) -> anyhow::Result<()>` | 从 JSON 加载（`:70`） |
| `load_translations_map` | `(&mut self, locale, map: HashMap<String, String>)` | 从 map 加载（`:77`） |
| `t` | `(&self, key: &str, args: &[(&str, &str)]) -> String` | 取翻译并格式化（`:82`） |
| `current_locale` | `(&self) -> &str` | 当前语言（`:119`） |
| `set_locale` | `(&mut self, locale: &str)` | 切换语言（`:124`） |
| `available_locales` | `(&self) -> Vec<&str>` | 已加载语言（`:129`） |
| `load_locale_dir` | `(&mut self, dir) -> anyhow::Result<Vec<Locale>>` | 加载目录（`:139`，非 WASM） |

`Default` 实现等价于 `new("en")`（`:176`）。

## 全局管理器

把管理器设为 `Global`，即可在任意 `Render`/`App` 中读取、切换：

```rust
fn run_example() {
    application().run(|cx: &mut App| {
        let mut i18n = I18nManager::new("zh-CN").with_fallback("en");
        i18n.load_translations_map("zh-CN", zh_map);
        i18n.load_translations_map("en", en_map);
        cx.set_global(i18n);
        // ... open_window ...
    });
}
```

切换语言用 `update_global`（回调签名 `|manager, cx|`）：

```rust
div().id("lang-en").on_click(cx.listener(|_, _, _, cx| {
    cx.update_global::<I18nManager, _>(|m, _| m.set_locale("en"));
}));
```

读取用 `try_global`（未设置时返回 `None`）或 `global`（未设置时 panic）：

```rust
let has_i18n = cx.try_global::<I18nManager>().is_some();
```

## I18nText 组件

`I18nText` 承载 key + 参数，在渲染时按全局管理器翻译；未设置全局管理器时
回退为 key 本身（`i18n/mod.rs:215`）：

```rust
I18nText::new("greeting")
    .with_arg("name", "rgpui")
    .translate_global(cx)              // &App
```

- `I18nText::new(key)`（`:192`）
- `I18nText::with_arg(key, value)`（`:200`）可链式多次
- `I18nText::translate(&I18nManager) -> String`（`:206`）用指定管理器翻译
- `I18nText::translate_global(&App) -> String`（`:218`）用全局管理器翻译

## 复数规则

`PluralRule` 在 `count == 1` 时取单数 key，否则复数 key，并以 `{count}` 作为
格式化参数（`i18n/mod.rs:227`）：

```rust
let one = PluralRule::new(1, "item", "items");
let many = PluralRule::new(5, "item", "items");
one.translate(&i18n);   // 取 "item"，参数 count=1
many.translate(&i18n);  // 取 "items"，参数 count=5
```

注意：这是**英文式**的单/复数二选一，不含各语言复杂复数规则。

## 语言目录加载

非 WASM 平台可用 `load_locale_dir` 批量加载一个目录下所有 `<locale>.json`
（`i18n/mod.rs:139`）：

```rust
#[cfg(not(target_family = "wasm"))]
let loaded: Vec<String> = i18n.load_locale_dir("locales")?;
```

- 目录下每个 `<locale>.json`（如 `zh-CN.json`）按文件名作为语言代码加载。
- 非 `.json` 文件与子目录跳过；任一条目解析失败即返回 `Err`。
- 返回成功加载的语言列表（已排序）。

临时切换语言后回退：

```rust
let snap = i18n.snapshot();
i18n.set_locale("ja");
i18n.restore(snap);   // 回到快照时语言
```

## 最佳实践

- **默认给回退语言**：`I18nManager::new("zh-CN").with_fallback("en")`，缺 key 时不至于显示 key。
- **命名空间化 key**：用 `menu.save`、`dialog.confirm` 之类分组，避免扁平 key 冲突。
- **插值只做简单替换**：`{name}` 是纯字符串替换，不做复数/性别/数字格式化，复杂场景先在 Rust 侧算好再传入。
- **全局单例足够**：多应用复用同一语言目录时各设各的 `Global` 即可，不必为共享做过度设计。
